# Гардероб Claude

Мод для Claude Code: на поле ввода стоит маленький пиксельный маскот Claude.
Он покачивается и моргает, а пока Claude работает над ответом — стучит лапками.
Его можно наряжать: котик, пират, дворецкий, волшебник, аниме, поэт, детектив,
капитан звездолёта, мишка, придворный — или сшить новый костюм по описанию:
его нарисует модель Claude, и маскот наденет его поверх себя, оставив лицо открытым.

Костюм чисто визуальный: на ответы Claude он не влияет.

## Установка

В терминальной сессии Claude Code:

```
/plugin install costumes --marketplace Borya78zzz/claude-costumes
```

Из обычной командной строки:

```
claude plugin install costumes --marketplace Borya78zzz/claude-costumes
```

В десктопном приложении, где `/plugin` не работает: нажми **+** рядом с полем ввода,
затем **Plugins** → **Add marketplace** с `Borya78zzz/claude-costumes` → **Add plugin**.

## Как пользоваться

- **👗** рядом с маскотом над полем ввода открывает гардероб.
- `/costume` — открыть гардероб, `/costume cat` — надеть костюм сразу, `/costume off` — снять.
- **Сшить новый** в гардеробе или `/costume-sew костюм динозавра` — сшить костюм по описанию.
  Шитьё занимает 10–30 секунд и тратит один запрос к модели Sonnet из лимитов твоего аккаунта.
  Сшитые костюмы (до 12) лежат в гардеробе, ненужный можно «Распороть».

Выбранный костюм сохраняется между сессиями.
